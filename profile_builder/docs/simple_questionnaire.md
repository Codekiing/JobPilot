# 用户画像简版问卷

问卷共 12 题。除标记为必填的题目外均可留空；第一组件已经准确识别的内容无需机械重复。

1. **基本情况与职业阶段（必填）**：请用一句话说明姓名、当前城市、职业阶段和求职状态；联系方式有变化时一并填写。
2. **目标岗位（必填）**：你希望找什么类型的工作和哪些岗位？请按优先级填写。
3. **地点与办公方式（必填）**：首选和可接受的工作城市有哪些？是否接受远程、混合办公或搬迁？
4. **入职与实习安排（必填）**：最早何时可以入职？如果考虑实习，请说明每周天数、持续月数和转正意愿。
5. **薪资期望**：最低和期望税前月薪是多少？对年终薪数是否有要求？
6. **技能与核心优势（必填）**：最希望岗位匹配突出哪些技能、领域能力或个人优势？
7. **经历与成果证据**：补充最能证明能力的 1–3 项经历或量化成果；简历已有内容可不重复。
8. **行业与公司偏好**：偏好或排除哪些行业、业务方向、公司规模或发展阶段？
9. **求职硬约束**：有哪些不能接受的工作条件？对出差和加班强度有什么要求？
10. **语言与工作许可**：说明可用于工作的语言水平，以及拥有工作许可的国家或地区。
11. **匹配规则偏好**：岗位描述中有哪些必须词、加分词或排除词？
12. **其他补充**：还有哪些会影响你选择岗位的信息？没有可留空。

## 处理顺序

1. 规则层识别日期、城市、岗位类型、薪资、实习时长、办公方式、公司偏好和硬约束等明确表达。
2. 规则结果直接写入画像，并在 `questionnaire.rule_enrichment.changed_fields` 中记录来源。
3. 如启用模型，模型只分析规则无法稳定处理的自由文本，只能补充仍为空的允许字段。
4. 模型不能覆盖简历或规则已经确认的值；每个模型补丁必须带置信度和问卷答案引用。
5. 更新完成度及 `match_ready`，最终写入 `profile.json`。
