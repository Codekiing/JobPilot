# 用户画像字段设计依据

第二组件的目标不是复刻任一招聘平台的个人简历，而是建立一份稳定、可解释、适合作为第三组件“岗位匹配”输入的候选人画像。

## 字段来源

- BOSS 直聘的公开协议列出了在线简历及求职期望中的联系方式、教育、工作经历、期望城市、期望薪资、期望行业和期望岗位。因此画像将“候选人证据”和“目标/偏好”分开存储，并把城市、岗位、行业、薪资作为核心匹配轴：[BOSS 直聘用户协议](https://www.zhipin.com/web/common/protocol/protocol-2019-09-30.html)。
- BOSS 职位页通常呈现岗位名称、城市、区域、经验、学历、月薪、薪数、岗位职责和要求，因此薪资使用“月薪上下限 + 薪数”，技能保留证据引用：[BOSS 大模型岗位列表](https://www.zhipin.com/zhaopin/fbceb91fbe7dc2991nd42N24/)。
- 实习僧的公开筛选项包含实习月份、每周到岗天数、学历、转正机会和日薪，因此实习画像单独设置 `days_per_week`、`duration_months`、`conversion_intent`：[实习僧职位筛选](https://www.shixiseng.com/interns/)。
- 牛客职位页包含薪资、技能标签、城市、学历、经验、岗位职责、岗位要求及公司阶段等信息，因此画像同时记录技能、学历、经验证据和公司偏好：[牛客职位示例](https://www.nowcoder.com/jobs/detail/60895)。
- OfferShow 提供公司与校招薪资查询入口，说明薪资和目标公司是校招决策的重要补充维度：[OfferShow](https://offershow.cn/jobs/homepage)。
- 公司招聘官网经常按毕业窗口、岗位类别、招聘项目和工作地点做资格筛选。阿里职位页明确展示毕业日期、岗位类别、招聘项目和城市；腾讯海外招聘 FAQ 还涉及实习时长与工作许可：[阿里职位示例](https://campus-talent.alibaba.com/campus/position/199903540003)、[腾讯招聘 FAQ](https://careers.tencent.com/m/zh-cn/faqdetail.html)。
- 大模型岗位本身还存在细分技术方向，例如强化学习、Agent、预训练、视觉、语音和具身智能，因此画像保留“主岗位 + 次岗位 + 技术/业务方向”三层表达：[字节跳动 Seed 招聘](https://seed.bytedance.com/zh/career)。

## 最终栏目

1. `identity`：姓名与联系方式，仅用于求职流程，不参与能力打分。
2. `career`：职业阶段、求职状态、当前城市、最高学历、毕业日期、经验月数。
3. `target`：求职类型、主次岗位、行业、城市、办公方式、入职时间、薪资与实习可用性。
4. `capabilities`：标准化技能、用户确认的核心优势、工作语言。
5. `evidence`：教育、工作/实习、项目、论文、奖项和量化成果，所有技能推断均可回指证据。
6. `preferences`：公司规模、融资/发展阶段、业务方向与文化偏好。
7. `constraints`：搬迁、出差、工作许可、加班偏好和不可接受条件。
8. `matching_config`：必须词、加分词、排除词和第三组件使用的默认权重。
9. `questionnaire`：用户回答历史；`completion`：完成度及岗位匹配就绪状态。

## 公平性边界

默认不采集或使用性别、民族、婚育、宗教、健康状况等敏感属性。年龄也不作为岗位匹配特征；校招资格使用毕业年月和招聘项目要求进行判断。
